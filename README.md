# market-data：复盘数据程序

为「三地股市复盘」（早报、晚报）提供数据的程序，以后也会给「期权交易」系统共用。
程序负责**拉数据、算指标、按规则分级**，Claude 负责**结合新闻做判断、写报告**。

- 仓库：`dengliang68-sudo/market-data`（公开）
- 当前版本：v0.2（2026-11-07，新增期权模块）
- 自动运行：GitHub Actions（`.github/workflows/daily.yml`）——早报数据 06:37、晚报数据 16:23、期权数据 20:23（21:23、22:23、次日 06:53 各补跑一次，报告已有就跳过；北京时间）；Tushare Key 存在仓库的 Secrets 里
- 运行环境：Claude 的云端会话（每次定时任务新开一个，跑完即清空）

---

## 一、它在系统里的位置

```
定时任务（早报 7:22 / 晚报 16:48）
   │
   ├─ 1. 读项目文档：复盘系统说明、持仓与观察池、信号追踪
   ├─ 2. clone 本仓库 → 运行 run_review.py → 得到"数据摘要"
   │        ├─ Tushare：A股、港股、期权、国际指数
   │        └─ FRED：标普500、纳指100、VIX、美债10年
   ├─ 3. 网络搜索补充：涨跌原因、新闻、公告、事件日历
   ├─ 4. 写报告（对程序的自动分级做二次筛选）
   ├─ 5. 把新的缓存数据和数据摘要提交回本仓库
   └─ 6. 推送报告给用户
```

## 二、功能清单

### 1. 美股指数基金面板（早报、晚报都有）

数据来源：FRED，取近 3 年日线。

| 输出项 | 含义 |
|---|---|
| `close` / `pct` | 标普 500、纳指 100 最新收盘和当日涨跌幅 |
| `high_52w` | 52 周最高收盘 |
| `drawdown_52w` | 距 52 周高点的回撤（%），**用来判断加仓档位** |
| `vs_ma50` / `vs_ma200` | 相对 50 日、200 日均线的位置（%） |
| `ret_12m` | 过去 12 个月涨幅（%） |
| VIX、美债 10Y | 最新值和日期 |
| 温度 | 自动判断：**偏冷**（回撤超过 10% 或 VIX≥25）、**偏热**（回撤小于 2%、高于 50 日线 4% 以上、VIX<15）、其他为**中性** |
| 已触及的回撤档位 | 标普 500 回撤达到 −5 / −10 / −15 / −20% 中的哪几档（每档是否已用过，要对照项目里的建仓进度表） |
| 过热条件 | 卖出规则第 3 条的三项里，可以自动判断的两项：12 个月涨幅是否超过 30%、是否跌破 200 日线。估值分位要另外查 |

### 2. A股大盘温度（晚报）

| 输出项 | 含义 |
|---|---|
| 主要指数 | 上证、深证成指、创业板指、科创 50、沪深 300 的收盘、涨跌幅、成交额 |
| 两市成交额 | 上证综指加深证综指（覆盖全部沪深股票），单位亿元 |
| 成交额倍数 | 今天成交额 ÷ 前 20 个交易日的平均值 |
| 涨跌家数 | 全市场上涨、下跌的股票数 |
| 涨停、跌停、炸板、最高连板 | 来自涨跌停统计 |
| 两融余额 | 最近 5 个交易日，沪深合计，单位亿元 |
| 南向净买入 | 港股通买入减卖出，单位亿元，通常比 A股晚一天更新 |

### 3. 港股指数（早报、晚报）

恒生指数、恒生科技指数的最新收盘和涨跌幅。

### 4. 趋势雷达：全板块自动扫描（晚报）

**扫描范围**：申万一级行业（31 个）、申万二级行业（134 个）、同花顺行业指数、同花顺概念指数，合计约 2000 个。同名指数只保留一个，申万优先。

**历史长度**：每个指数取最近 130 个交易日。

**分级规则**（对应《复盘系统说明》第五节，程序能自动判断的部分）：

| 等级 | 程序的判断方法 |
|---|---|
| ⚪ 观察 | 两条量价条件都满足：① 连续 3 天涨幅排进全部板块的前 10%；② 当天成交量 ≥ 前 20 日均量的 1.5 倍。或者满足其中一条，同时满足一条准备级条件 |
| 🟡 准备 | 至少一条观察级条件，加上：站上 20 日和 60 日均线、20 日均线比 5 天前高，并且收盘创 60 日新高 |
| 🟢 可介入 | 准备级基础上，近 15 天内出现过放量创 60 日新高（量 ≥ 20 日均量 1.3 倍），之后缩量回调、没有跌破 20 日线，今天再次放量上涨 |
| 🔴 退潮·今日新出现 | 近 20 天创过阶段新高（处在高位），今天放量跌破 20 日线，或放量下跌超过 4% |
| 🔴 退潮·持续退潮 | 近 40 天创过约半年新高，现已跌破 20 日线、20 日线拐头向下，距 40 日高点回撤超过 10% |

**每个板块输出的指标**：

| 字段 | 含义 |
|---|---|
| `src` | 来源：申万 / 同花顺行业 / 同花顺概念 |
| `pct` / `pct5` / `pct20` | 当日、5 日、20 日涨跌幅（%） |
| `vol_ratio` | 当日成交量 ÷ 前 20 日均量 |
| `dist_ma20_pct` | 距 20 日均线（%） |
| `high60` | 是否创 60 日新高 |
| `top10pct_3d` | 是否连续 3 天涨幅排进前 10% |
| `dd_from_40d_high` | 距 40 日高点的回撤（%） |
| `group` | 按名称关键词归类：科技 / 医药 / 其他 |

**程序不判断、需要 Claude 结合新闻补充的**："明确催化"（政策、产业事件、业绩）、"上涨扩散"（是不是只有一两只股票在拉）、资金流和板块的对应关系。

### 5. 科技、医药板块速览（晚报）

从全部板块里按关键词挑出科技相关（半导体、光模块、PCB、算力、AI、机器人、通信、电子、计算机等）和医药相关（创新药、CXO、医疗、生物、中药、器械等）的板块，分别列出当天涨幅前 8 名和后 5 名。

### 6. 资金流（晚报）

东方财富口径的行业、概念资金流，取最近 5 个交易日：
- **持续流入**：5 天里至少 4 天净流入的板块，按 5 日合计净流入排序
- **今日流出最多**：当天净流出最多的板块

### 7. ETF 期权模块（`run_options.py`，每个交易日 20:23 运行，供次日 8:17 期权盘前简报使用）

保护：最近交易日的期权/ETF 日线还没出来时（如开盘前运行）自动退回上一个交易日；任何品种的平值 IV 取不到时报错退出、不写报告（Actions 显示失败）。手动补某一天：Run workflow 选 opt，date 填 YYYYMMDD。

覆盖 5 个品种：50ETF、300ETF、500ETF、科创50ETF、创业板ETF。规则对应「期权交易」项目的交易指引。

| 输出 | 内容 |
|---|---|
| 趋势状态 | 上升 = 收盘 > MA20 > MA60 且 MA20 比 5 天前高；下降反之；其他、或近 10 天穿越 20 日线 ≥3 次 = 震荡 |
| 关键位 | MA20、MA60、MA20 的 5 日斜率、前 20 日最高/最低收盘和最高/最低价、量比 |
| 自动触发 | 放量（≥20 日均量 1.3 倍）突破 20 日高点 / 跌破 20 日低点；上升趋势中回调到 20 日线后转向上；下降趋势中反弹到 20 日线后转向下；大阳线/大阴线（涨跌 ≥2%，是否"重大政策/数据后第一根"由简报判断） |
| 隐含波动率 | 当月、次月平值 IV（Black-Scholes，用收盘价反推，无风险利率取 Shibor 3M）；近 60 个交易日的 IV 均值和分位；IV 水平：分位 <30 偏低、>70 偏高 |
| 持仓结构 | 当月+次月的成交 PCR、持仓 PCR；认购最大持仓行权价（压力）、认沽最大持仓行权价（支撑） |
| 合约日历 | 各品种当月、次月到期日和剩余天数；剩余 <10 天标"不新开"，20–45 天标"适合" |
| 候选合约 | Delta 0.4–0.6、排除分红调整合约（合约单位不是 10000），列出代码、行权价、收盘价、每张权利金、IV、Delta、持仓量、成交量；优先剩余 20–45 天的月份，没有就列出所有剩余 ≥10 天的月份 |

输出文件：`reports/YYYYMMDD_opt.md` 和 `.json`（日期是数据所属交易日）；缓存 `data/opt_daily_sse.parquet`、`data/opt_daily_szse.parquet`（保留 80 个交易日）。

## 四、使用方法

```bash
pip install -r requirements.txt --break-system-packages
export TS_TOKEN=<Tushare Key>          # Key 只放在环境变量里，不要写进仓库

python run_review.py --session pm      # 晚报：全部功能
python run_review.py --session am      # 早报：美股指数基金面板 + 港股指数
python run_review.py --session pm --date 20261106   # 指定某个 A股交易日重跑
```

**耗时**：第一次运行要回填 130 个交易日的板块数据，约 6 分钟；之后只补新日期，约 30 秒。

**输出文件**：

| 路径 | 内容 |
|---|---|
| `reports/YYYYMMDD_am.md`、`reports/YYYYMMDD_pm.md` | 数据摘要（同时打印到屏幕，供写报告用） |
| `reports/YYYYMMDD_am.json`、`reports/YYYYMMDD_pm.json` | 全部结构化数据，包括每个板块的完整指标 |
| `data/sw_daily.parquet` | 申万行业日线缓存（保留 180 个交易日） |
| `data/ths_daily.parquet` | 同花顺指数日线缓存（保留 180 个交易日） |
| `data/ths_index.parquet` | 同花顺指数名单 |
| `data/moneyflow_ind_dc.parquet` | 行业、概念资金流缓存（保留 30 个交易日） |

**缓存机制**：按交易日增量保存。已有的日期不再请求，最近 2 个交易日每次都重新拉一遍，防止盘后数据修正。运行后要把 `data/` 提交回仓库，下次才能接着用。

## 五、代码结构

| 文件 | 内容 |
|---|---|
| `run_review.py` | 主程序：按早报、晚报组织各模块，生成数据摘要 |
| `md/client.py` | Tushare 调用（遇到频率限制自动等待重试）、交易日历、按日期增量缓存、FRED 下载 |
| `md/signals.py` | 趋势雷达的分级规则 |
| `md/cn.py` | A股大盘温度、板块扫描、资金流、港股指数、科技和医药关键词 |
| `md/us.py` | 美股指数基金面板 |
| `md/opt.py` | ETF 期权：趋势状态、触发、Black-Scholes 隐含波动率和 Delta、PCR、合约日历、候选合约 |
| `run_options.py` | 期权主程序 |
| `requirements.txt` | 依赖：tushare、pandas、pyarrow、requests |

## 六、安全

- Tushare Key 只通过环境变量 `TS_TOKEN` 传入，**不写进仓库任何文件**。
- Key 目前保存在两个定时任务的指令里，只有账号本人能看到。如果泄露，到 Tushare 后台重新生成，再更新两个定时任务。
